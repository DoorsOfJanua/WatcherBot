## Design Context

### Users

MyAgentRoom is first and foremost Janua's private desktop-and-phone workspace for delegating real work to a persistent team of AI agents. He uses Telegram while away from the computer and AgentHQ/MyAgentRoom when he wants to see conversations, project state, active work, evidence, and approvals in one place. The core job is to leave a project with agents, return later, and continue from an accurate current state without re-explaining prior discussions or making agents rediscover completed work.

### Brand Personality

Alive, playful, and trustworthy. Agents should feel like distinct characters sharing a workshop: expressive and sometimes funny, but precise about project truth, authority, uncertainty, and completed actions. The experience should feel companionable rather than corporate and dependable rather than theatrical.

### Aesthetic Direction

A messaging workspace with the immediacy of Grok Bot, enriched by original animated agent spirits and persistent project rooms. Desktop favors an agent/project sidebar, a generous central conversation-and-work surface, and a quiet contextual rail for live state, evidence, approvals, and progress. Mobile preserves the same core authority through an adapted app shell. Avoid generic admin dashboards, card-grid overload, terminal cosplay, crypto aesthetics, noisy queue chatter, and interfaces where chat history substitutes for project state.

### Design Principles

1. **Return, never restart.** Opening a project immediately reveals what it is, where it stands, what changed, and what needs Janua.
2. **Project truth precedes conversation.** Canonical project files and append-only decisions feed every agent turn; chat is an interface to that state, not its source of truth.
3. **Show meaningful change.** Prefer state deltas, evidence, milestones, blockers, and decisions over backend status noise.
4. **Alive without becoming a chorus.** Character, motion, and bounded agent-to-agent conversation create delight; one clear owner and sparse interjections preserve focus.
5. **Authority stays visible.** Research, drafts, and organization may proceed autonomously. Sending, publishing, spending, deleting, deploying, and changing canonical decisions require the appropriate explicit approval.
6. **Same project, every surface.** Telegram and AgentHQ/MyAgentRoom must resolve the same project identity, state, decisions, missions, and agent identities.
7. **Evidence survives interpretation.** Preserve sources and history, label uncertainty, show why the project portrait changed, and let Janua's corrections outrank inference.
